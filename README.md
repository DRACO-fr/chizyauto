# Chizy Auto Styling website

Static website (HTML + CSS + a little JS). No build step.

All files, including the images, sit in the repo root next to `index.html`.

## Deploy on GitHub Pages
Settings > Pages > branch `main`, folder `/ (root)`, then save.

## Editing
- Contact details are in the "Find us" section and the script at the bottom of `index.html` (WhatsApp number `27670227499`).
- Products are the `<article class="card">` blocks. Put new photos in the root and reference them by filename.
- Colours are the CSS variables at the top of the `<style>` block.
